\chapter{Fact Sheet: Measured Properties of the Thesis System}\label{app:factsheet}

This appendix collects, on one page, every number about the thesis system that
the guide relies on. \emph{Measured} values come from
\file{docs/research_guide/scripts/measure_workload.py} run on the thesis code
(\cref{st:workload:reproduce}). \emph{Estimates} are derived by hand from the
code, and \cref{ch:workload} shows how. Thesis results are quoted from the
thesis repository~\cite{burrell2026thesis}. If you change the thesis code, rerun
the script and update this page first.
